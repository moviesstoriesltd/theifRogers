## GitHub Search Strategy

GitHub search benefits from exact project terms in headings, tables, filenames, and repeated
technical identifiers. The README now includes:

- Framework and library names: `Next.js`, `React`, `Tailwind CSS`, `Framer Motion`.
- Route names: `/`, `/report`, `/about`, `/sitemap.xml`, `/robots.txt`.
- Data filenames: `Leif_L_Rogers.json`, `app/site.js`, `app/report/page.jsx`.
- Repository-purpose terms: public records, litigation report, OSINT dashboard, medical board.

## Google Indexing Strategy

The README now supports external indexing with:

- A descriptive H1 containing the entity, topic, and technology.
- A 150-160 character meta-description-style summary.
- Keyword clusters distributed across natural sections.
- Route-level intent mapping for long-tail discovery.
- Clear documentation links to deepen topical relevance.
- Professional source-accuracy language to support trust signals.

## Anti-Stuffing Guardrails

- Keywords are used only where they clarify the project.
- No hidden text, doorway-page language, or repetitive keyword blocks.
- Allegations, findings, and unverified leads are described as content categories rather than
  unsupported factual conclusions.
- Technical accuracy is prioritized over search-volume language.

## Recommended Future Improvements
